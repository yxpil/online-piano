# online-piano

指尖钢琴 · 在线 MIDI 合成钢琴 — Web Audio 实时合成 36 种音色，支持 MIDI 多轨多音色播放 / 导出、屏幕触控、电脑键盘与外接 Web MIDI 键盘

**主要语言**：JavaScript

**标签**：`browser` `midi` `music` `piano` `synthesizer` `tailwindcss` `vanilla-javascript` `web-audio` `web-midi`
